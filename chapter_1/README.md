# Chapter 1: A Tutorial Introduction

This directory contains exercises and examples from Chapter 1 of *The C Programming Language*. 

## Overview
This chapter introduces the fundamental concepts of C, including:
- Getting started (Hello, World!)
- Variables and arithmetic expressions
- `for` and `while` loops
- Symbolic constants
- Character input and output
- Arrays
- Functions
- Character arrays
- External variables and scope

Source files for the exercises are located in the `src/` directory, and it is recommended to place compiled binaries in the `bin/` directory.
