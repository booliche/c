# The C Programming Language - Exercises

This repository contains my solutions to **every** exercise from the classic book *"The C Programming Language"* by Brian W. Kernighan and Dennis M. Ritchie (often referred to as K&R).

## Structure
The exercises are organized by chapter in their respective folders (e.g., `chapter_1`).

## How to Compile

You can compile the exercises using a standard C compiler like `gcc` or `clang`. 

For example, to compile an exercise from Chapter 1, navigate to the project root and run:

```bash
gcc -o chapter_1/bin/excercise_1_2 chapter_1/src/excercise_1_2.c
```

Then run the compiled executable:

```bash
./chapter_1/bin/excercise_1_2
```
